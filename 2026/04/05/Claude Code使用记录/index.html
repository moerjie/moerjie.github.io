Claude Code使用记录

1 Claude Code 安装使用

以下 Claude Code 全部以 CC 代替
最好在电脑配置 nodejs 环境

1.1 安装

给出 win 终端安装 Native Claude Code 的步骤
PowerShell：irm https://claude.ai/install.ps1 | iex
CMD：curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
目前使用上面官方命令安装 Native 版本的 CC 会报错，可以先使用 npm 安装 CC，然后执行在终端执行 claude install --force 以安装 Native 版本的 CC。
npm 安装 CC：npm install -g @anthropic-ai/claude-code

[!note]+
需 git 环境，推荐在 Windows 新版 terminal 使用 CC

更详细的安装步骤和使用说明见 Claude Code Docs
