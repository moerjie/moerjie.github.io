5G相关知识学习记录

1 PWS概览

5G 公共预警系统（Public Warning System）是 3GPP 为移动通信系统定义的一种公共服务系统，旨在利用 5G 的低延迟、高可靠性和大容量特性，在自然灾害或公共安全事件等紧急条件下，向公众快速广泛的传播紧急警报和关键信息。

1.1 PWS 的预警类型和承载信息

5G 网络通过专用的系统信息块（SIB）承载不同的公共预警消息：

  1. SIB6（ETWS 主要通知）：承载地震和海啸预警系统（ETWS）的主要通知，仅包含简单的灾难模式信息，如“地震”、“海啸”，数据量极小以确保能以最快的速度传输；
  2. SIB7（ETWS 辅助通知）：承载 ETWS 的辅助通知，包含详细的信息，如震中、地震强度等具体灾情信息；
  3. SIB8（CMAS 警告通知）：承载商业移动警报系统（CMAS）的警报。CMAS 支持更广泛的紧急事件类型，通常分为三类：总统或区域权力机构发布的警报、涉及生命安全迫在眉睫的威胁警报（极端/严重威胁）、以及琥珀色警报（儿童绑架紧急情况）等。 3GPP 还定义了其他区域的 PWS 子系统，利用与 CMAS 相同的底层接入机制进行工作。

1.2 PWS 网络架构和核心组件

5G PWS 引入了基于服务的架构（SBA），大幅提升预警消息的传递效率。系统核心组件如下：

  1. CBE（小区广播实体）：负责预警消息的格式化，包括将长消息拆分成多个页面。属于第三方网元（如气象局、地震局）；
  2. CBCF（小区广播中心功能）：位于 5G 核心网，负责管理 CBS 信息，包括分配序列号、确定广播的小区集合、设定广播的开始与停止时间、分配紧急指示等，通过基于服务的接口与 AMF 进行通信；
  3. AMF（接入和移动性管理功能）：作为 CBCF 与无线接入网（NG-RAN）之间的桥梁，负责处理地域定向广播请求，并根据跟踪区域码（TA）将消息下发至目标基站；
  4. NEF（网络开发功能）：对外提供标准化 API，允许第三方权威机构直接触发预警请求；
  5. NG-RAN（5G 基站）：调度无线资源，广播 SIB6、7、8 消息，并通过寻呼功能通知终端接受预警信息。

1.3 端到端消息传递机制

一个完整的 5G PWS 预警流程通常在 ms-s 级完成，具体步骤如下：

  1. 触发与生成：权威机构监测到灾害，通过 NEF 或直接向 CBCF 发送预警请求；
  2. 核心网处理：CBCF 将预警内容进行封装，通过 N50 接口想目标区域的 AMF 发送“Write-Repalce Warning Request”（写入-替换警告请求）；
  3. 无线侧广播：AMF 通过 N2 接口将请求转发给目标 gNodeB，gNodeB 接收到请求后，立即调度 SIB 资源，更新 SIB1 中的调度信息，并高频词广播 SIB6、7、8 预警内容；
  4. 终端接收与告警：处于空闲（RRC_IDLE）、非激活（RRC_INACTIVE）或连接（RRC_CONNECTED）状态的 UE 在寻呼时机监听 SIB1。当发现紧急指示标志置位时，立即接收 SIB6/7/8，验证通过后触发本地声、光、震动等多模态警报。

1.4 优势

  • 极速响应：5G 超低时延特性使地震预警从震中到手机仅需 0.3 秒，比 4G CBS 快数倍。ETWS 主通知要求在 4 秒内送达。
  • 精准地理定向：支持“地理定位”功能，允许系统向特定地理区域发送警报，确保只有受影响地区的个人收到信息，避免全城恐慌。
  • 强制推模式：采用小区广播技术，无需接收确认。即使终端处于空闲状态，甚至在无 SIM 卡或欠费状态下也能被强制唤醒接收预警，到达率极高。
  • 免鉴权接入：5G 网络对紧急情况下的用户接入进行了免鉴权和认证的特殊规定，开机的终端均可接收预警消息。
  • 多模态提醒：支持文字、特殊铃声（如 ETWS 专属警报音）、震动等特殊指示，且不允许用户转发或复制粘贴预警内容.

2 5G 网络架构

5G 系统包括核心网、接入网和终端部分。核心网和接入网之间需要进行用户平面和控制平面的接口连接；接入网和终端间通过无线空口协议进行连接。

2.1 UE

5G 网络的终端设备，通过 Uu 接口与基站通信。

Uu 是 5G NR 的无线接口，负责：

  1. 无线信号传输
  2. 调制解调
  3. MIMO 空间复用
  4. OFDM 传输
  5. 上下行数据传输

2.2 RAN（Radio Access Network，无线接入网）

RAN（Radio Access Network）负责无线信号接入和空口资源管理，核心设备为 gNB（5G 基站）。

5G 采用 CU/DU 分离架构：

  • DU（Distributed Unit）：负责低层实时处理，如物理层、MAC 层等，通常靠近基站部署。
  • CU（Centralized Unit）：负责高层协议处理，如 RRC、PDCP 等，可集中部署。 主要接口：
  • Uu 接口：UE 与 gNB 之间的无线接口。
  • Xn 接口：不同 gNB 之间的互连接口，用于切换和协同。
  • F1 接口：CU 与 DU 之间的接口。
  • NG 接口：RAN 与 5GC 之间的接口。

2.3 5GC（5G Core Network）

5GC（5G Core Network）采用 服务化架构（SBA，Service Based Architecture），并实现控制面与用户面分离（CUPS）。

2.3.1 控制面功能

负责用户注册、认证、移动管理和会话控制：

  • AMF：接入与移动性管理，负责 UE 注册和移动管理。
  • SMF：会话管理，负责 PDU 会话建立和 UPF 选择。
  • UDM：用户数据管理，保存用户签约信息。
  • AUSF：用户认证。
  • PCF：策略控制和 QoS 管理。
  • NEF：网络能力开放。

2.3.2 用户面功能

  • UPF（User Plane Function）：负责用户数据转发，是 5G 网络连接外部数据网络的核心节点。

3 5G 频谱和信道安排

频谱是无线通信最重要的资源，其有两个重要特征，即频率的高低和可用带宽的大小。频率高低与覆盖范围密切相关，频率越低覆盖距离越远。可用带宽与容量密切相关，基站/UE 最大发射带宽通常为中心频率的 5%左右，因此频率越高，可用带宽越大。
