GPS HDL Acquisition and Tracking Using CA Code 实验报告

1 实验说明

1.1 实验目的

  1. 理解 GPS L1 C/A 信号的捕获和跟踪的基本流程。
  2. 掌握基于 FFT 的频域相关捕获方法。
  3. 掌握 GPS 跟踪环路中的 FLL、PLL、DLL 的原理和作用。
  4. 结合 GPS HDL Acquisition and Tracking Using C/A Code 修改为适合特有硬件的工程。
  5. 掌握适合 HDL 生成的 simulink 模型设计方法。

1.2 实验原理

GPS L1 C/A 码接收机通常包含捕获和跟踪两个部分。

1.2.1 捕获

该工程采用基于 FFT 的频域相关捕获方法，具体原理见 [[GPS捕获算法]]。

1.2.2 跟踪

跟踪模块采用 FLL、PLL、DLL 进行 Track，原理见 [[GPS跟踪算法]]。

2.1.1 Control Acquisition

第一级为 Control Acquisition 模块，功能如下：

  1. 生成 1ms 脉冲信号；
  2. 收到 start 后输出与 1ms 脉冲对齐的 startAcq 信号，后续 start 信号不生效，收到 AcqDone 或 reset 后，拉低 startAcq 并输出复位跟踪信号；
  3. 输出重新排序后的 PRN，顺序为 0 9 17 25， 1 10 18 26， 2 11 19 27， 3 12 20 28， 4 13 21 29， 5 14 22 30， 6 15 23 31， 7 16 24 32， 8。 模块框图如下： Hold Acquisition 模块如下图：

工作逻辑为：

  1. Delay 模块初始值为 0，取反后反馈至 AND2 输入 1，即 ready 为 1，当 start 拉高，AND2 输出 1，再经过 OR2、OR1 拉高 startAcq，输出到外部后通过 SR_startAcq 模块进行保持，并且此时 Delay 处于使能更新状态，由于 Switch 模块 port2 为 0，输出为 1，经过 Delay=>NOT2 后，ready 信号为 0，AND2 的输入 1 始终为 0，此时再来 start 信号也无效。
  2. 当捕获完成、AcqDone 为 1 并且没有复位时：AND1 输出 1，Switch 输出 0，Dealy 下一拍输出 0，ready 信号为 1，可以通过 start 信号重新启动捕获。
  3. 当收到 reset 信号，通过 OR1 输出 startAcq 信号，并且通过 OR1 和 OR3 驱动 AND3，输出 resetTrackChannel 信号。

2.1.2 RAM Read and Write

RAM Read and Write 模块如图所示：

功能为：

  1. 将 1ms 的 RxData 写入到 RAM 。
  2. 以 252MHz 系统时钟循环读取 RAM 中的数据。 关键节点的信号如下图所示： RAM Read Logic 模块同时生成捕获时需要的频率索引信号等，框图如下： 当 RAM 写满后，ramWriteDone 拉高一次，通过锁存器驱动生成 RAM Read Address，直到所有频率、搜索轮次完成后，stopRAMRead 拉高，停止读取 RAM 中的信号。

逻辑电路的逻辑大概为：

  1. reset 为 0，ramWriteDone 为 1 时，第一个 switch 输出 true，第二个 switch 输出 F 路的 true，同时 Delay 模块被使能，输出拉高；
  2. 若有 reset 信号，第二个 switch 输出 false，同时 Delay 模块被使能，输出 0；
  3. stopRAMRead 被拉高，此时 ramWriteDone 和 reset 都为 0，Delay 模块同样输出 0，停止读取 RAM 信号。

2.1.3 Carrier Wipeoff

Carrier Wipeoff 模块如图所示：

freqInd 范围换算成-10~+10，其中 NCO 累加器位宽 N为 14，因此可得：

$$ \begin{align} phinc=\frac{f}{f_s}\times2^N=f\times \frac{16384}{16384000} \end{align} $$

$f$ 的范围是要搜索的多普勒频移的范围，为 $\pm 10kHz$，对应的 phinc 的范围正好为 $\pm 10$。

NCO 输出取共轭进行负频率混频，消除载波中的多普勒频移。

2.1.4 Correlation

Correlation 模块如图所示：

如果有复位信号，通过 subsystem 延长 valid 的有效时间，保证 FFT block 中的数据能全部输出，subsystem 如图所示：

两个比较器的判定条件都为 ==param.fftLen-1，工作流程为：

  1. 当 validIn 输入，经过 OR 后驱动 validOut 输出；
  2. 当 reset 拉高，前级的validIn 拉低，此时如果 count 的计数值不为 0，说明已经有数据送入 FFT 模块内，并且此时计数值也不为 fftLen-1 时，此时给使能触发器置 1，继续通过 OR 逻辑门驱动 validOut 输出高电平信号；
  3. 当计数值== param.fftLen-1 后，与 OR 门输出相与后复位使能触发器，终止 validOut 输出。

subsystem2如下图所示： 工作流程为：

  1. 当收到 reset 信号后，拉低 enb 信号输出；
  2. reset 信号通过使能触发器持续拉高，直到计数值等于33028 后，复位使能触发器，如果此时 reset 信号已拉低，则通过 OR 逻辑门输出 0，取反后重新使能 enb 信号输出。 Generate Code Phase and Pop Signal内部框图如图所示： 搜索完 21 个多普勒频率后 POP 出下一个 PRN 进行捕获，搜索完整个码相位+所有频率后输出 POP 信号。其中输出码相位的范围为 0~param.fftLen。

2.1.5 Sort and Prepare Outputs

模块框图如下：

上一个模块输出的捕获结果是 4 路并行，首先通过 Serializer 将输入串行处理，然后通过 Sort Function 进行排序输出。

当有效项不超过 8 个时，它只保证前 inpSize - 1 或 numSorts - 1 项完成排序。这个设计通常是为了避开捕获里的 PRN=0 噪声参考项/最弱项；输出接口仍固定给 8 路，后级再根据 PRNIDSort ~= 0 判断哪些通道是真正有效卫星。并且计算卫星有效通道的总数，如果＜4 路就复位，重新进行捕获。
